# V2.1a — API ציבורי ומפתחות API

## מה נבנה

| רכיב | פירוט |
|------|-------|
| **הפעלה** | פיצ'ר "API ציבורי למשתמשים" (מיתוג › פיצ'רים), **כבוי כברירת מחדל**. כשהוא כבוי, מפתחות קיימים מחזירים 403 `api_disabled` ודף המפתחות מחזיר 404. |
| **מפתחות** | חשבון › מפתחות API: שם, הרשאות (`agents:read`, `conversations:write`, `approvals:write`), הגבלה לסוכנים מסוימים ותוקף (30/90/365 יום או ללא הגבלה). המפתח `ra_sk_<id>_<secret>` מוצג פעם אחת. נשמר רק hash מסוג SHA-256, וההשוואה נעשית בזמן קבוע. עד 20 מפתחות פעילים למשתמש. ביטול בשני שלבים. |
| **ניהול** | ניהול › מפתחות API: כל המפתחות הפעילים עם הבעלים, שימוש אחרון ושיחות ב־30 הימים האחרונים. אנשי צוות יכולים לבטל כל מפתח (נרשם ב־Audit). |
| **API** | `GET /agents`, `POST/GET /conversations`, `GET/DELETE /conversations/{id}`, `POST /conversations/{id}/messages`, `GET /runs/{id}`, `GET /runs/{id}/events` (SSE), `POST /runs/{id}/cancel`, `POST /approvals/{id}`, ו־`/openapi.json` ציבורי (OpenAPI 3.1). תיעוד למפתחים: `docs/API.md`. |
| **מסלול קוד אחד** | התחלת שיחה והמשכה הועברו ל־`lib/server/conversations.ts`. גם האתר וגם ה־API משתמשים בו, כך שהמכסות, שריון הקרדיטים, נעילת השיחה והבעלות זהים. אין מסלול שעוקף חיוב. |
| **שיחות** | נשמר מקור השיחה (`WEB`/`API`) והמפתח שהתחיל אותה. שיחות מה־API מופיעות גם בהיסטוריה של המשתמש באתר. |

## אבטחה
- **אימות ושגיאות:** אימות בכל בקשה. מפתח לא מוכר, מבוטל או שפג תוקפו נראים זהים (401). ניסיונות כושלים מוגבלים ל־20 בדקה לכל לקוח, ושימוש תקין ל־120 בקשות בדקה לכל מפתח, בנוסף למגבלות ההרצה של המשתמש.
- **בעלות:** הבעלות והגבלת הסוכנים של המפתח הן חלק מכל שאילתה (BOLA). משאב של משתמש אחר או סוכן לא מורשה מחזיר 404. אישור פעולה נבדק מול הגבלת הסוכנים **לפני** ההחלטה.
- **קלט:** הגוף מוגבל ל־64KB, מחייב `application/json`, ושדות לא מוכרים נדחים.
- **CORS:** אין כותרות CORS, כך שדפדפן באתר אחר לא יכול לקרוא ל־API. ה־Widget יגיע בנפרד, עם מפתח ציבורי מוגבל (V2.1b).
- **מה לא נחשף:** אף תשובה לא חושפת הוראות מערכת, מודל, ספק או עלות פנימית.

## פרטיות ומסמכים
- **מסמכים משפטיים:** כשה־API פעיל, מדיניות הפרטיות כוללת שורה על מפתחות API, ותנאי השימוש כוללים סעיף API (ב־4 שפות, נוצר אוטומטית).
- **ייצוא מידע:** ייצוא המידע של המשתמש כולל את פרטי המפתחות (בלי hash) ואת מקור כל שיחה.
- **Checklist:** מפת המידע וה־Checklist עודכנו.

## תיקון שנמצא בדרך
שדה חובה שלא נשלח בכלל (ה־API מאפשר זאת, הטופס לא) החזיר הודעה גנרית של Zod. עכשיו מוחזר `required`, בדיוק כמו בטופס.

## בדיקות
- **יחידה:** shared 63 (כולל המקרה שלמעלה), web 46 (OpenAPI: כל `$ref` נפתר, וכל נתיב ומתודה קיימים בקוד).
- **`api-e2e` (69):**
  - **אימות:** 401, 403 (scope, כיבוי), 429.
  - **בקשות:** 400, 404 ו־422 עם שדות.
  - **שיחה מלאה:** SSE עם טקסט חלקי, המשך, אישור פעולה, 409 (busy, אין המשך, החלטה כפולה), דפדוף, מחיקה.
  - **הרשאות:** BOLA בכל 7 הנתיבים מול משתמש אחר, הגבלת סוכנים, ביטול על ידי המשתמש ועל ידי הצוות.
  - **כללי:** CORS, ייצוא מידע, axe על הדפים.
