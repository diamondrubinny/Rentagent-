# רכיבי קוד פתוח שמותר להטמיע במוצר

## הקריטריונים
- **רישיון מתירני:** MIT, ISC, BSD או Apache-2.0. רישיונות כאלה מאפשרים שימוש מסחרי והפצה בתוך מוצר סגור, בתנאי שמצרפים את הודעת הרישיון. ה־SBOM ב־CI כבר אוכף את זה.
- **פרויקט פעיל:** היה עדכון בחודשים האחרונים.
- **התאמה אמיתית:** הרכיב חוסך עבודה בשלב מתוכנן, ולא מוסיף תלות "סתם".

הרישיונות והגרסאות נבדקו מול ה־npm registry ב־30.10.2026. **לפני הוספה בפועל יש לבדוק שוב את קובץ ה־LICENSE בגרסה שנבחרה.** מומלץ גם לבדוק עם עורך דין את מדיניות הרישיונות הכללית (ראו `PRODUCTION-CHECKLIST.md`).

## מומלץ להטמיע

| רכיב | רישיון | מה הוא ייתן לנו | שלב |
|------|--------|------------------|-----|
| **ALTCHA** (`altcha-lib` 2.8 בשרת, `altcha` 3.5 בדפדפן) | MIT | הגנה מבוטים בלי Google ובלי עוגיות: הדפדפן פותר חידה חישובית קטנה ברקע. כולו מתארח אצלנו (בלי צד שלישי), אז אין צורך ב־DPA או בהסכמה לעוגיות. | **V2.1b** (פתיחת שיחה ב־Widget), ובהמשך גם הרשמה ואיפוס סיסמה |
| **croner** (11.0) | MIT | פענוח ואימות של ביטויי cron עם אזורי זמן, וחישוב ההרצה הבאה. | V2.2 |
| **grammY** (1.46) | MIT | ספרייה בשלה ל־Telegram Bot API: webhooks, אימות secret token ו־TypeScript מלא. | V2.3 |
| **promptfoo** (0.125) | MIT | הרצת Evals: מערכי בדיקה, assertions ושופט מודל. אפשר להשתמש בו כספרייה בתוך ה־worker או לאמץ רק את הפורמט שלו. | V2.4 |
| **gVisor** (`runsc`) | Apache-2.0 (חלק מהקבצים BSD-3) | בידוד ברמת kernel לקונטיינר שמריץ קוד של סוכן. משתלב ב־Docker כ־runtime. | V2.6 |
| **mammoth** (1.13) | BSD-2-Clause | המרת קבצי Word ‏(.docx) לטקסט למאגר הידע. היום יש תמיכה ב־PDF בלבד, דרך `unpdf`. | שיפור קטן ל־RAG |
| **Scalar API Reference** (1.76) | MIT | דף תיעוד אינטראקטיבי ל־API מתוך ה־OpenAPI הקיים. יש לארוז אותו מקומית ולא לטעון מ־CDN (CSP ופרטיות). | אחרי V2.1 (אופציונלי) |
| **Microsoft Presidio** | MIT (Python, שירות נפרד) | זיהוי והתממה של מידע אישי (טלפונים, ת"ז וכו') לפני שליחה לספק AI או לפני הפיכת דירוג למקרה בדיקה. הגבלה: הזיהוי לא מושלם. | V2.4, ואופציה למפעילים רגישים |

## כבר בשימוש
- **הרצת סוכנים וכלים:** Vercel AI SDK ‏(Apache-2.0), ‏`@modelcontextprotocol/sdk` ‏(MIT), ‏`unpdf` ‏(MIT).
- **בסיס נתונים ותורים:** pgvector ‏(PostgreSQL License), BullMQ ‏(MIT).
- **אימות משתמשים:** Better Auth ‏(MIT).
- **בדיקות נגישות:** axe-core ‏(MPL-2.0, רק בבדיקות). **סריקת קבצים:** ClamAV ‏(GPL, רץ כקונטיינר נפרד ולא מוטמע בקוד).
