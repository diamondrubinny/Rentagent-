# שלב 3 — ספקי AI, מודלים, ניתוב ומדידת עלויות

## היקף
| רכיב | פירוט |
|------|-------|
| ספקים | OpenAI · Anthropic · Google Gemini · Mistral · xAI · DeepSeek · Groq · Together · Fireworks · Perplexity · Cohere · OpenRouter · Azure OpenAI · Amazon Bedrock · **כל שרת תואם OpenAI** (Ollama, vLLM, LM Studio, שרתים פנימיים) — דרך Vercel AI SDK 7. התמיכה בכל ספק **דורשת אימות מול התיעוד הרשמי** לפני פרודקשן. |
| מפתחות | כמה מפתחות לכל ספק, מוצפנים (AES-256-GCM, מקושרים למזהה המפתח), מוצגים רק 4 תווים אחרונים, תקרת הוצאה חודשית לכל מפתח, הפעלה/כיבוי, בחירה מעגלית, "צינון" אוטומטי של מפתח שנכשל באימות או בהגבלת קצב |
| מודלים | Registry בבסיס הנתונים: ייבוא מה־API של הספק (כשיש) או הוספה ידנית; סוג (צ'אט/Embeddings), יכולות (כלים, תמונה, JSON, reasoning), חלון הקשר, שפות, **עלות** (מה שהספק גובה) ו**מחיר** (מה שהמשתמש משלם) לכל מיליון טוקנים, נראות, הפעלה |
| בלי מחירים בקוד | אין מזהי מודלים או מחירים מקודדים — הם משתנים תדיר; המפעיל מייבא ומעדכן. OpenRouter מחזיר מחירים בייבוא — מוצגים כהצעה לאימות |
| ניתוב | מדיניות ניתוב: `fixed` (סדר קבוע), `cheapest`, `fastest` (לפי זמן תגובה נמדד), עם **שרשרת fallback**: מעבר אוטומטי למודל/ספק הבא בשגיאות זמניות (429, 5xx, timeout, רשת, מפתח חסום) — לא בשגיאות קלט |
| Streaming | fallback אפשרי עד הטוקן הראשון; אחריו הזרם ממשיך מאותו מודל |
| מדידה | רשומת שימוש לכל קריאה: ספק, מודל, מפתח, משתמש, מטרה, טוקנים, עלות, מחיר, זמן, הצלחה/שגיאה, ניסיונות fallback |
| Kill-switch | כיבוי גלובלי של כל ה־AI, ספק, מפתח או מודל — מיידי |
| ניהול | `/admin/providers`, `/admin/providers/[id]` (הגדרות, מפתחות, מודלים, בדיקת חיבור), `/admin/routing`, `/admin/playground` (בדיקה חיה עם streaming), `/admin/usage` |
| הרשאה | `providers.manage` (בעלים ומנהלי מערכת) + 2FA |

## אבטחה
- מפתחות לעולם לא חוזרים לדפדפן; פענוח רק בזמן קריאה לספק, בשרת.
- כתובות Base URL: רק http/https, בלי פרטי התחברות ב־URL, חסימת כתובות metadata של ענן (169.254.0.0/16, fe80::/10, `metadata.google.internal` ועוד). כתובות פנימיות (כמו `http://ollama:11434`) מותרות בכוונה — המפעיל מגדיר אותן, עם MFA.
- תשובות שגיאה מהספק לא מוצגות גולמית למשתמשי קצה (עלולות להכיל מידע פנימי) — רק סוג השגיאה; הפרטים ביומן השרת בלי התוכן.
- Audit לכל שינוי בספקים, מפתחות, מודלים, ניתוב ו־kill-switch.
- תוכן הפרומפטים לא נשמר ברשומות השימוש — רק מספרים.

## פרטיות
- כל קריאה שולחת את התוכן לספק החיצוני שנבחר. במסך המודל מוצג הספק; מדיניות הפרטיות (שלב 7) תפרט את זה. המפעיל אחראי לבדוק DPA ותנאי שימוש בנתונים מול כל ספק — **דורש בדיקה משפטית**.

## בדיקות שבוצעו
- יחידה (חבילת `ai-gateway`): 59 בדיקות — יצירת מודל לכל 15 סוגי הספקים בלי רשת, סיווג שגיאות (401/403/429/5xx/רשת/timeout/סינון תוכן), סדר ניתוב (קבוע/זול/מהיר), שרשרת fallback, חישוב עלות מדויק ב־BigInt (כולל עיגול כלפי מעלה ונפחים של מיליארדי טוקנים), ייבוא מודלים לכל פורמט (OpenAI, Anthropic עם דפדוף, Google בלי מפתח ב־URL, Cohere, OpenRouter עם מחירים), הגנת SSRF.
- E2E מול שרת AI מדומה (תואם OpenAI) — כולן עברו, גם מול ה־image של Docker (מערכת קבצים לקריאה בלבד):
  - כתובת metadata של ענן נחסמת; המפתח הסודי לא מופיע ב־HTML, רק 4 תווים אחרונים; מוצפן ב־DB.
  - בדיקת מפתח תקין (רשימת מודלים) ומפתח מוגבל (הודעת rate limit).
  - ייבוא מודלים (מתחילים כבויים), ייבוא חוזר לא מכפיל; מחיר לא תקין נדחה.
  - מדיניות ניתוב: מודל שנכשל (500) → מעבר אוטומטי למודל הבא; תשובה ב־streaming; מסלול הניסיונות מוצג.
  - עלות מחושבת נכון (1000 טוקני קלט × $1 + 500 פלט × $2 ל־1M = ‎$0.002) ומחיר למשתמש (‎0.005).
  - רוטציית מפתחות: מפתח עם 429 מזוהה ומושהה, הקריאות ממשיכות להצליח עם המפתח השני.
  - עצירת חירום חוסמת קריאות ומשתחררת.
  - ה־API של ה־playground דוחה בקשות אנונימיות ו־cross-origin.
  - יומן ביקורת מכיל את כל אירועי ה־AI. axe ‏(WCAG 2.1 AA) ב־5 מסכים: 0 הפרות. 0 שגיאות CSP/קונסול.
- רגרסיה: E2E של שלב 2 (43 בדיקות) עבר שוב.

## באגים שנמצאו ותוקנו
- **עקיפת חסימת metadata**: כתובת IPv4 בתוך IPv6 בכתיב hex (`[::ffff:a9fe:a9fe]`) עברה את החסימה → תוקן ונוספו בדיקות.
- **ייבוא מודלים**: השתמש רק במפתח הראשון; מפתח מוגבל חסם את הייבוא → עכשיו מנסה את כל המפתחות הפעילים.

## מגבלות ודורש אימות
- כתובות ברירת המחדל, נקודות ה־API לרשימת מודלים ושמות ההגדרות של כל ספק — **דורשים אימות מול התיעוד הרשמי**; נבדקו כאן מול שרת מדומה בפורמט OpenAI בלבד, לא מול הספקים האמיתיים (אין מפתחות בסביבת הפיתוח).
- Azure ו־Bedrock: בלי ייבוא אוטומטי (מזהי deployment/מודל מוזנים ידנית).
- מחירים מ־OpenRouter מוצגים כהצעה בלבד — יש לאמת.
- Embeddings: הסוג קיים ב־Registry; השימוש בפועל (RAG) — שלב 4.
