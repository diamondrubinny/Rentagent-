# V2.2 — משימות מתוזמנות וטריגרים

## מה נבנה

| רכיב | פירוט |
|------|-------|
| **הפעלה** | פיצ'ר "משימות מתוזמנות" (מיתוג › פיצ'רים), **כבוי כברירת מחדל**. כשהוא כבוי, הדף מחזיר 404, הטריגרים מחזירים 401 וה־worker לא מריץ דבר. |
| **דף `/schedules`** | למשתמשים מחוברים. בוחרים סוכן, ממלאים את שדות המשימה וקובעים מתי היא תרוץ: כל שעה, כל יום, ימי חול, כל שבוע, cron מותאם, או רק מכתובת טריגר. בוחרים אזור זמן ורואים מראש את 3 ההרצות הבאות. אפשר לקבל מייל, להשהות ולחדש, להריץ עכשיו ולמחוק (בשני שלבים). עד 10 משימות למשתמש. |
| **מגבלות** | לכל היותר הרצה אחת בשעה. השרת והטופס בודקים את זה באותה פונקציה (`checkCron` ב־shared, מבוסס croner 10.0.1, MIT). כל הרצה נספרת במגבלה היומית של המשתמש ושומרת קרדיטים כמו צ'אט רגיל. "הרצה עכשיו" מוגבלת ל־5 פעמים בשעה. |
| **Worker** | בדיקה כל דקה. משימות שהגיע זמנן ננעלות עם `FOR UPDATE SKIP LOCKED`, והזמן הבא מתעדכן באותה טרנזקציה, כך שגם כמה workers במקביל לא מריצים את אותה הרצה פעמיים. |
| **טריגר נכנס** | `POST /api/hooks/schedules/<id>`, חתום כמו ה־webhooks היוצאים (`x-rentagent-signature: t=…,v1=…`). הסוד מוצג פעם אחת ונשמר מוצפן (AES-GCM). בקשה ישנה מ־5 דקות או בקשה שכבר התקבלה נדחות. הגוף מוגבל ל־64KB, ויש עד 60 קריאות בשעה. הגוף מחליף את `{{payload}}` בשדות המשימה (עד 8,000 תווים). |
| **התראות** | מייל כשהתוצאה מוכנה וכשפעולה ממתינה לאישור. המייל כולל **רק קישור**, בלי התשובה עצמה (צמצום מידע). 3 תבניות ב־4 שפות. |
| **כשלים** | אחרי 3 כישלונות ברצף המשימה מושהית אוטומטית, נשלח מייל עם הסיבה ונרשמת שורה ב־Audit. סיבות אפשריות: אין קרדיטים, מגבלה יומית, סוכן לא זמין, שדות לא תקינים או הרצה שנכשלה. חידוש המשימה מאפס את מונה הכישלונות. |
| **אישורים** | פעולה שדורשת אישור ממתינה לבעל המשימה, שמאשר אותה בצ'אט שלו. |

## ארכיטקטורה
- **קוד משותף:** הלוגיקה שמתחילה שיחה עברה מהאתר לחבילות, כדי שהאתר וה־worker יריצו בדיוק אותו קוד:
  - `reserveRunCredits` עבר ל־`@rentagent/billing`.
  - `loadRunnableAgent` ו־`createFirstTurn` עברו ל־`@rentagent/agent-runtime`.
  - האתר, ה־API, ה־Widget והמשימות המתוזמנות משתמשים עכשיו באותן פונקציות לשריון קרדיטים ולפתיחת שיחה.
- **טריגר והרצה עכשיו:** האתר רק מאמת את הבקשה ומכניס משימה לתור (`schedule-trigger`). ה־worker מריץ אותה. המשימה הזו **לא** מנסה שוב אוטומטית, כדי שלא תיווצר הרצה כפולה.

## פרטיות
- **מסמכים משפטיים:** כשהפיצ'ר פעיל, מדיניות הפרטיות כוללת שורה על משימות מתוזמנות ועל נתונים שמגיעים מטריגרים (4 שפות).
- **מחיקה:** מחיקת משימה משאירה את השיחות שלה בהיסטוריה, והקישור למשימה מתנתק.
