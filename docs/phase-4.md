## אבטחה
- **Fetch של סוכן חסום לכל הכתובות הפנימיות** (localhost, רשתות פרטיות, link-local, metadata) — בניגוד לכתובות ספקים שהמפעיל מגדיר. בדיקה גם אחרי DNS ובכל הפניה (redirect), מגבלת גודל וזמן, רק http/https, רשימת דומיינים מותרים אופציונלית לכל סוכן.
- **Prompt injection**: תוכן מכלים מסומן כמידע לא אמין בהנחיות; פעולות עם השפעה חיצונית (מייל, HTTP שאינו GET, MCP) דורשות אישור כברירת מחדל; כל כלי מקבל רק את ההרשאות שלו.
- **HTTP Tools**: רק המפעיל (OWNER/ADMIN) מגדיר; ה־URL נבנה מתבנית עם קידוד פרמטרים, המארח קבוע (המודל לא יכול לשנות אותו); כותרות סודיות מוצפנות.
- **קבצים**: רשימת סוגים מותרים, בדיקת תוכן (magic bytes / UTF-8 תקין), גודל מקסימלי 10MB, שם קובץ אקראי, אחסון מחוץ לתיקייה ציבורית, הסגר עד סריקה; קובץ נגוע נחסם ונרשם ביומן.
- **מגבלות**: תקרת צעדים, תקרת עלות לריצה (בודקת אחרי כל צעד), timeout כולל, rate limit להפעלת ריצות.
- הנחיות הסוכן ותוכן הריצות נשמרים ב־DB (נחוץ להמשך אחרי אישור); שמירה ומחיקה אוטומטית — שלב 7.

## בדיקות שבוצעו
- יחידה: `agent-runtime` ‏85 (חסימת כתובות פנימיות כולל IPv6 ממופה, מחשבון כולל קדימויות, חלוקת טקסט, זיהוי סוגי קבצים, חילוץ טקסט מ־PDF אמיתי, לולאת הסוכן, תבניות), `shared` ‏51 (סכמות סוכן, ייבוא/ייצוא, טופס קלט דינמי), `mail` ‏15, `ai-gateway` ‏59, `core` ‏10.
- E2E (Playwright) מול שרת AI מדומה עם tool calling ושרת MCP מדומה — 32 בדיקות, כולן עברו, **גם מול ה־images של Docker** (web + worker + migrate):
  - סוכן מתבנית → כלי מחשבון → תוצאה נכונה; הצעד נשמר.
  - סוכן ששולח מייל: הריצה נעצרת לאישור; אישור → המייל נשלח (עם הערת שקיפות "נשלח ע"י סוכן AI"); דחייה → לא נשלח. הריצה נקשרת לגרסה שפורסמה.
  - ידע: קובץ בינארי שמתחזה ל־txt נדחה (415); txt ו־PDF עוברים הסגר → נקי → אינדוקס ב־pgvector; התשובה מבוססת על המסמך ומציינת מקור.
  - Fetch של סוכן ל־127.0.0.1 נחסם.
  - HTTP Tool: כותרת סודית מוצפנת ב־DB ומפוענחת רק בזמן הקריאה; פרמטר עם `/` מקודד; placeholder במארח נדחה.
  - MCP עם Bearer: טעינת כלים, קריאה באישור.
  - ייצוא ללא מזהים פנימיים, דורש הרשאה (403 לאנונימי); ייבוא עם slug ייחודי.
  - יומן ביקורת מכיל אישורים ודחיות. axe ‏(WCAG 2.1 AA) ב־8 מסכים כולל עברית: 0 הפרות. 0 שגיאות CSP/קונסול.
  - אין סודות (מפתח API, כותרת HTTP, טוקן MCP) בלוגים, בצעדי ריצה, ביומן הביקורת או בטקסט גלוי ב־DB.
- רגרסיה: E2E של שלבים 2 ו־3 עברו שוב. `prisma migrate diff` ריק; `pnpm audit` — 0 חולשות.

## מגבלות ידועות בשלב זה
- הרצה ע"י משתמשי קצה (השכרה, תשלום) — שלב 5–6; כאן: תצוגה מקדימה ע"י צוות.
- Streaming ברמת טוקן בריצת סוכן — כרגע ברמת צעד.
- חיפוש ברשת (Web search) דורש ספק חיפוש — ניתן לחבר כ־HTTP Tool או MCP.
- DOCX, OCR, ייבוא אוטומטי של HTTP Tools מקובץ OpenAPI — בהמשך (כרגע הגדרה ידנית של כלי HTTP).
- ClamAV לא נבדק כאן מול שרת אמיתי (רק הפרוטוקול ביחידה); בלי ClamAV קבצים מסומנים "לא נסרקו" — מומלץ להפעיל בפרודקשן.
- שרת MCP נבדק רק מול שרת מדומה ב־Streamable HTTP; תאימות לשרתים ספציפיים — **דורש אימות מול התיעוד הרשמי** שלהם.
- טקסט שקיפות במיילים של סוכנים ותוכן שנוצר ע"י AI — **דורש בדיקה משפטית** (חוקי דיוור/ספאם, EU AI Act).
